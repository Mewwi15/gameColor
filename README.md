# ภารกิจส่งสีไป 3 เกาะ

เว็บเกมภาษาไทย 2 หน้า สร้างด้วย Next.js App Router, React และ TypeScript ใช้ภาพจากโฟลเดอร์ `reference` และ `UI`

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด http://127.0.0.1:4310 — หน้าเริ่มเกมอยู่ที่ `/` และหน้าเล่นอยู่ที่ `/play`

ใช้พอร์ต 4310 เพื่อไม่ชนกับแอปอื่นที่ใช้พอร์ต 3000 และ 3001 ในเครื่องนี้ และใช้ Webpack พร้อม polling สำหรับ dev server เพื่อรองรับสภาพแวดล้อมที่ใช้ FSEvent ของ Turbopack ไม่ได้

## กติกา

| สี | เกาะที่ตอบถูก |
| --- | --- |
| น้ำเงิน ฟ้า เขียว | โทนเย็น |
| แดง ส้ม ชมพู | โทนร้อน |
| ม่วง เหลือง | สองโทนเท่านั้น |

ม่วงและเหลืองเป็นได้ทั้งโทนร้อนและโทนเย็น แต่ในเกมนี้ตอบถูกเฉพาะเกาะสองโทนเท่านั้น หากส่งไปโทนร้อนหรือโทนเย็นจะแสดงเฉลยและให้ลองลูกเดิมใหม่ กติกาและคำเฉลยอยู่ใน `src/lib/game.ts`

- ลากด้วยเมาส์หรือนิ้ว หรือกดเลือกเกาะโดยตรง ใช้แป้น 1 / 2 / 3 ได้ด้วย
- ปุ่มขยายเต็มจออยู่ที่มุมขวาบนทั้งสองหน้า ใช้ปุ่มเดิมหรือ Esc เพื่อออก โหมดเต็มจอคงอยู่เมื่อกดเริ่มเกม
- รองรับ Fullscreen API และ Safari แบบมี prefix หากอุปกรณ์ไม่รองรับหรือเบราว์เซอร์ปฏิเสธ จะขยายพื้นที่เล่นเต็มหน้าต่างแทน โดยอาจยังเห็นแถบเครื่องมือเบราว์เซอร์
- มีลูกสีถัดไปรออยู่ในคิว เมื่อตอบถูกลูกบอลจะเคลื่อนไปยังเกาะและลูกถัดไปเลื่อนเข้ามาให้ลากต่อ วางนอกเกาะจะเลื่อนกลับจุดเดิม
- ตอบถูก: เสียงสำเร็จ พร้อมข้อความและเอฟเฟกต์ ก่อนเปลี่ยนลูกถัดไป
- ตอบผิด: เสียงแจ้งเตือน พร้อม Alert แสดงเฉลย กดลองใหม่แล้วเล่นลูกเดิมจนถูก
- ส่งครบทั้ง 8 สี: แสดงสรุปผลและเล่นใหม่ได้ โดยรอบใหม่สุ่มลำดับสี
- ปิดเสียงได้ การตั้งค่าเสียงบันทึกในเบราว์เซอร์
- เสียงตอบถูกใช้ `เสียงตอบถูก/เสียงตอบถูก.WAV` และเสียงตอบผิดใช้ `misTake/misTake.WAV` โดยคัดลอกไปไว้ใน `public/audio/`
- เพลงพื้นหลังถูกลดระดับในไฟล์เสียงลงเหลือ 25% และเล่นที่ระดับ 50% พร้อมลดลงอีกชั่วคราวระหว่างเล่นเอฟเฟกต์ เอฟเฟกต์เล่นที่ระดับ 95% และไม่ซ้อนทับกัน
- เพลงพื้นหลังจากไฟล์ `vidssave.com stream cafe - boba date ♥ (1 hour) _ cute music 144P.mp4` แยกเฉพาะเสียงไว้ที่ `public/audio/boba-date.m4a` เล่นวนซ้ำต่อเนื่องข้ามหน้า โดยใช้ปุ่มเสียงเดียวกัน
- พยายามเล่นเพลงเมื่อเปิดเว็บ หากเบราว์เซอร์บล็อก autoplay จะเริ่มเมื่อคลิก แตะ หรือกดแป้นครั้งแรก และเคารพการตั้งค่าปิดเสียงที่บันทึกไว้

## ตรวจสอบ

```bash
npm test
npm run typecheck
npm run test:e2e
npm run build
```

การทดสอบเบราว์เซอร์ใช้ Google Chrome ที่ติดตั้งในเครื่อง ครอบคลุมคอมพิวเตอร์และมือถือ

`npm test` ตรวจทั้งกติกาและการโต้ตอบของ React ใน JSDOM รวม 26 กรณี โดยจำลองเสียง Pointer API และ Fullscreen API; การตรวจภาพจริงและสัมผัสจริงอยู่ในชุด `test:e2e` ซึ่งยังรันไม่สำเร็จใน sandbox นี้ เนื่องจาก Chrome ถูกปิดขณะเริ่มทำงาน

รันแบบ production ด้วย `npm run build` ตามด้วย `npm start` ที่ http://127.0.0.1:4310
